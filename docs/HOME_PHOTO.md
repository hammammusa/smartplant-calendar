# صورة الصفحة الرئيسية

تعرض الصفحة الرئيسية الآن رسمًا متجهيًا لمدرّجات زيتون وحقل خضار (`src/components/home/terraces-art.tsx`). يُحمَّل الرسم مع الموقع، فلا يحتاج إلى أي خدمة صور خارجية.

لاستبداله بصورة حقيقية:

1. اختر صورة تملكها أو مرخّصة للاستخدام، مثل أرض زراعية أو حديقة أو مدرّجات زيتون في فلسطين.
2. شغّل الأمر التالي:
   ```bash
   npm run images:home -- path/to/photo.jpg
   ```
   ينتج الأمر ثلاثة أحجام WebP في `public/images/home/`، ويحذف بيانات الكاميرا والموقع الجغرافي من الصورة، ثم يطبع إعدادات جاهزة.
3. الصق الإعدادات في `src/content/home-photo.ts` بدل `null`، ثم اكتب:
   - `alt`: وصفًا عربيًا للصورة؛
   - `credit`: اسم المصوّر أو الترخيص.

تُعرض الصورة بالحجم المناسب لكل شاشة (`srcset`).
